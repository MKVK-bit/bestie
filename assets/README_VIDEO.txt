HOW TO ADD YOUR BIRTHDAY VIDEO
--------------------------------
1. Edit your birthday wishes video as you like.
2. Save/export it as an MP4 file.
3. Rename it exactly to:      birthday-wish.mp4
4. Put that file inside this "assets" folder.
5. Open birthday.html - it will play automatically.

Optional poster image (the preview picture before play):
- Save any photo as:   video-poster.jpg
- Put it in this same "assets" folder.
